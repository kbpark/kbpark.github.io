# 🎻 바이올리니스트 메이커 (Violinist Maker)

가상의 유럽풍 세계관 '세브지크 아카데미'를 배경으로 한
**모바일 웹 기반 클리커 + 미연시 하이브리드 게임**.

> 강당 청소부 출신 낙하산 견습생 **레온 베르나델**이,
> 얼음공주 라이벌 **바이올렛 드 기욤**과 함께 10곡의 무대를 완주하며
> 크레모나 광장의 해피엔딩에 이르는 이야기.

---

## 실행 방법
외부 의존성/빌드 도구가 전혀 없습니다. `index.html`을 브라우저로 열면 즉시 실행됩니다.
> 모듈이 아닌 classic `<script>` 로 구성해 `file://` 더블클릭 실행도 지원합니다.
> (권장) VS Code Live Server 등 로컬 서버로 열면 모바일 실기기 테스트가 편합니다.

## 디렉터리 구조
```
violinist-maker/
├── index.html          # UI 뼈대 (진입점)
├── css/
│   └── style.css       # 모바일 레이아웃 · 레트로 도트 테마 · 대사창
├── js/
│   ├── data.js         # 캐릭터/4대 스킬/10곡 퀘스트/대사·선택지·엔딩 (순수 데이터)
│   ├── state.js        # 상태(포인트·스킬·사랑 게이지·설정) + LocalStorage 자동 저장·복원
│   ├── portraits.js    # 인라인 SVG 캐릭터 초상(표정) + 엔딩 CG 생성
│   ├── audio.js        # Web Audio 합성 엔진(곡별 BGM·타건음·팡파레·뮤트)
│   ├── ui.js           # DOM 렌더링 · 미연시 대사창(선택지) · 사랑 게이지 · 엔딩
│   └── game.js         # 클리커/보잉 · 스킬업 · 퀘스트/사랑 게이지 분기 · 메인 루프
├── assets/
│   ├── img/
│   │   ├── characters/ # 레온·바이올렛·안드레아 입 그림 (도트/웹툰풍)
│   │   ├── cg/         # 이벤트 CG (엔딩 고백 등)
│   │   └── ui/         # 버튼·프레임 등 UI 스프라이트
│   ├── sprites/        # 도트 스프라이트 시트
│   └── audio/          # BGM · 효과음 (곡별 클립)
└── README.md
```

## 아키텍처 (관심사 분리)
| 모듈 | 책임 | 전역 |
|------|------|------|
| `data.js`  | 밸런스/시나리오 데이터 | `GameData` |
| `state.js` | 진행 상태·저장/복원      | `GameState` |
| `ui.js`    | 화면 표현·대사창          | `UI` |
| `game.js`  | 규칙·루프 (state↔ui 연결) | `Game` |

로드 순서: **data → state → ui → game** (index.html 하단 참고).

## 구현된 기능
- ✅ 모바일 세로 레이아웃 (flex 컬럼, 480px 폰 프레임, 노치 대응)
- ✅ 수동 탭 → 연습 포인트 · 4대 스킬(음정·박자·보잉·표현력) 업그레이드
- ✅ 보잉 = 자동 클릭(초당 포인트) → `requestAnimationFrame` 루프
- ✅ 10곡 퀘스트 진행 + 조건 충족 시 연주(클리어) 판정
- ✅ **캐릭터 일러스트**: 인라인 SVG 초상(레온·바이올렛·안드레아), 표정 8종
- ✅ **사운드**: Web Audio 합성 — 탭마다 곡 멜로디 1음씩, 곡별 BGM 루프, 클리어 팡파레, 🔊 뮤트
- ✅ **사랑 게이지·대사 분기**: 바이올렛 사랑 게이지(0~100) + 선택지 → 음악 탐구/동료/연심 티어별 대사·표정 변화
- ✅ **엔딩 CG**: 사랑 게이지 ≥50 사랑 엔딩 / 미만 음악성 엔딩, 크레모나 광장 SVG 연출 + 다시하기
- ✅ LocalStorage 10초 자동 저장 + 종료 시 저장 + 복원

## 방치형 시스템 (Particle Clicker 벤치마킹)
- **🤝 조력자** — 자동 수익 6단계(메트로놈→후배→반주자→실내악→오케스트라→조교). 많이 살수록 비용 상승.
- **🛒 상점 업그레이드** — 일회성 배수(송진 탭×2, 명품활 자동×2, 스트라디바리우스 전체×2 …). 조건 충족 시 해금.
- **🏆 업적** — 마일스톤 11종, 일부는 전체 획득 영구 +보너스. 달성 시 토스트 알림.
- **🏠 오프라인 수익** — 자리를 비운 시간만큼 조력자 수익을 정산(효율 50%, 최대 8시간)해 복귀 시 팝업.
- **QoL** — 구매 수량 **x1/x10/최대** 토글, 탭 시 **+N 플로팅**, **탭 UI**(스킬/조력자/상점/업적)로 정리.
- 스킬 효과가 겹치지 않도록 분리: 🎯음정·💜표현력=탭당, 🏹보잉=자동, ⏱️박자=전체 배수.

## 밸런스/연출 튜닝 포인트
- 스킬 `baseCost·growth`, 퀘스트 `req` 레벨 → `data.js`
- 곡별 멜로디·BPM·음색(오실레이터/필터/비브라토) → `audio.js`
- 초상 외형·표정, 엔딩 CG 씬 → `portraits.js`
- 대사·선택지·사랑 게이지 증감·엔딩 분기값 → `data.js` / `game.js`(`ROMANCE_ENDING_MIN`)
