처음 오셨나요? 사용법 가이드

1. 곡 등록 및 악보 스캔
메인 화면의 버튼을 눌러 곡 제목을 입력하고 PDF 파일을 업로드하세요.

2. 마디 에디터 설정 (중요!)
[마디 에디터 열기]를 눌러 악보 위를 마우스나 손가락으로 드래그하세요. 사각형을 그리면 해당 영역을 기준으로 마디들이 자동으로 생성됩니다.
* 생성된 마디의 / 버튼으로 세부 마디 수를 조절할 수 있습니다.

3. 연습 모드 시작
등록된 곡을 클릭하면 연습이 시작됩니다. '산적의 마디 정복'은 지능형 알고리즘을 사용합니다.

  • 먼저 개별 마디(1마디씩)를 '상'으로 정복하세요.
  • 연속된 마디들이 모두 익숙해지면, 앱이 자동으로 2마디, 3마디씩 묶어서 더 길게 연습하도록 대기열을 만들어줍니다.

4. 평가 및 정복
연습 후 [상, 중, 하] 버튼으로 본인의 숙련도를 평가하세요. '상'을 받은 마디는 다음 단계(더 긴 연결 연습)로 넘어가는 열쇠가 됩니다.
